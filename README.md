# 📈 Customer Segmentation using K-Means Clustering

Proyek *Machine Learning* berbasis *Unsupervised Learning* yang menerapkan algoritma **K-Means Clustering** untuk mengelompokkan data segmentasi pelanggan berdasarkan karakteristik tertentu[cite: 10]. Proyek ini mencakup proses *Exploratory Data Analysis* (EDA), standarisasi data, penentuan jumlah cluster optimal (*Elbow Method*), serta visualisasi hasil klasterisasi menggunakan Python.

## ✨ Fitur & Komponen Utama
* **Jupyter Notebook (`EDA_Kmeans.ipynb`):** Berisi langkah-langkah lengkap mulai dari pra-pemrosesan data (*data preprocessing*), visualisasi EDA, hingga penerapan model K-Means[cite: 10].
* **Dataset Pelanggan (`segmentation data.csv`):** Dataset utama yang digunakan untuk proses analisis klaster.
* **Kamus Data (`segmentation data legend.xlsx`):** Penjelasan rinci mengenai variabel dan atribut data yang dianalisis[cite: 10].

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook / Google Colaboratory[cite: 10]
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
